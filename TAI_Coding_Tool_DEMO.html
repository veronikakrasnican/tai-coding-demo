⚠ You are viewing the demo version of the TAI Coding Tool. All participant responses shown are fictional and created for demonstration purposes only. The real project data is stored securely and accessible only to the research team.

What is this tool?

This is a purpose-built qualitative coding environment developed for the Yathiqu project. It allows a research team to systematically code workshop responses against the 10-characteristic Trustworthy AI (TAI) taxonomy, track review progress, and visualise results — all in real time, from any device, with no software to install.

Why did we build it instead of buying software?

Commercial qualitative data analysis tools (such as NVivo, ATLAS.ti, or MAXQDA) are powerful but come with significant constraints for a project like this:

  • Cost: per-seat annual licences typically range from €300–€800 per researcher per year.
  • Collaboration: most tools are desktop-based and do not support live multi-user editing on shared data.
  • Flexibility: generic tools are not designed around the specific coding scheme, framework, or workflow of any one project.
  • Live results: no commercial tool provides a live dashboard that updates as coding decisions are made.

By building a custom tool, we retained full control over the coding scheme, made collaboration seamless across international sites, and produced live analytical outputs — at zero recurring cost.

How was it built?

The tool is built entirely from free, open-source components. A researcher with basic technical knowledge can reproduce it without specialist infrastructure or commercial software licences.

Database
Supabase (PostgreSQL)
Cloud database with a free tier. Stores all responses and coding decisions. Accessible via a standard REST API. Free up to 500MB — more than sufficient for workshop data.
Frontend
Plain HTML / JavaScript
A single HTML file. No framework, no build tools, no dependencies. Reads and writes to Supabase directly from the browser. Can be opened locally or hosted online.
Hosting
GitHub Pages
Free static site hosting. Upload the HTML file to a GitHub repository and it is available at a permanent public URL within minutes. No server required.
Data preparation
Python
Used once to convert raw CSV files from the workshop data collection system into database records, preparing the data for systematic human review.

What does it do?

  • Three-dimensional coding — each response is coded for which TAI characteristic it references, how well it aligns with the formal definition (Full / Partial / Not aligned / Emergent), and the participant's sentiment toward AI.
  • Live dashboard — characteristic frequency, sentiment distribution, and alignment breakdown update in real time as coding decisions are saved.
  • Emergent theme detection — responses that do not fit any existing characteristic are automatically surfaced, signalling potential gaps in the theoretical framework.
  • Multi-user collaboration — any number of reviewers can work simultaneously. Changes are visible to all users immediately.
  • CSV export — the full coded dataset can be exported at any point for further analysis in R, Python, or any statistical software.

Can other projects use it?

Yes. The tool is designed to be adaptable. Any project using a predefined coding framework — academic integrity, AI ethics, patient safety, education research — can replace the TAI characteristics with its own codes and deploy the same system. The core infrastructure (Supabase + GitHub Pages + Python) remains identical.
